# NetLearn

An interactive course on multiplayer networking for Unity developers. It has four modules:

1. **Networking for Games**: the theory
2. **Unity Netcode for GameObjects**
3. **Steamworks with Facepunch**
4. **NGO + Steam Together**

The course includes live network simulators, animated diagrams, quizzes, module exams with certificates, spaced-repetition flashcards, a glossary and full-text search. Progress is stored in the browser.

Built with Astro, MDX, React islands, Tailwind and Pagefind, and deployed to GitHub Pages.

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm verify     # content validation + type check + unit tests + build
```

See [CONTRIBUTING.md](CONTRIBUTING.md) to add modules, lessons, quizzes, simulators or diagrams.
